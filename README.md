# My Website

### It's live @ [www.oriperelman.com](https://www.oriperelman.com)

## Development

Use Node 26.11.1 (`nvm use`), then run `npm install` and `npm run develop`.
Run `npm run build` to verify a production build.

This branch has been build-tested on Node 26.11.1, but Gatsby 5.16.1 and some
Gatsby plugins declare support for Node versions below 26. npm therefore emits
engine warnings; Node 26 is currently a best-effort local target, not an
upstream-supported runtime.
